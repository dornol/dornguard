## DornGuard v0.0.2

- Run `layered` and `hexagonal` architecture checks in Maven reactors. The
  archive includes the Maven project model extension, and module checks use
  Maven's declared source roots.
- Audit Maven runtime dependency versions with `dornguard audit` and
  OSV-Scanner. Check CSP headers separately with `dornguard csp`.
- Enable optional profiles for JSpecify coverage, JSP, HTML, and JavaScript.
  Thymeleaf checks include restricted Spring bean references, with an
  optional profile for reviewing unescaped expressions.
- Suppress an intentional finding through a Java source comment or a
  fingerprint-based `ignore` entry. Add a reason alongside the suppression.
- On Ubuntu, including WSL, install missing system packages and set up
  Semgrep and PMD with `sh scripts/install.sh v0.0.2 --with-deps`.

### Upgrading from v0.0.1

The built-in ruleset is now `1.1.0`. If your configuration pins
`ruleset.version: "1.0.0"`, update it to `"1.1.0"` when upgrading DornGuard.
Keep the top-level configuration `version: 1`. Configurations that use the
bundled ruleset without a version pin pick up the new rules automatically.

Java, Kotlin, and Spring profiles now report more warnings about imports,
exception handling, coroutine cancellation, and Spring proxies or shared
state. Spring's field injection rule skips Java test sources under
`src/test/java`. The `jspecify` profile is opt-in and reports a missing
`@NullMarked` scope as an error.

See the [profile reference](https://github.com/dornol/dornguard/blob/v0.0.2/docs/profiles.md)
and [full comparison](https://github.com/dornol/dornguard/compare/v0.0.1...v0.0.2).
