## DornGuard v0.0.5

Release archives are available for Linux x86-64 (AMD64) and macOS ARM64.

- PMD coverage lists the files checked with a compiled classpath and those
  checked in source-only mode. Look for `pmd_coverage` in JSON reports.
- Set `thymeleaf_partial_parsing: warning` to tolerate partial parsing of
  Thymeleaf templates. A check with only these analysis warnings and no
  blocking findings exits with `0` and reports `status: incomplete` and
  `complete: false`. Baseline creation still requires complete analysis.
- Set `format.indent_style` and `format.control_spacing` globally or in
  file-specific overrides. Use `format.exclude` to skip formatting for
  selected paths. Formatting skips minified JavaScript by default. Set
  `format.include_minified: true` to include it again.
- Use a rule family such as `"format.*"` in a file or directory ignore
  entry. Fingerprint ignores still use an exact rule ID.

### Upgrading from v0.0.4

Use built-in ruleset `1.3.0` and top-level configuration `version: 1`.
Install the CLI and bundled JVM artifacts together. The ArchUnit runner uses
protocol 4.

JSON check reports use version 3. Consumers that validate `status` should
accept `incomplete`. If your CI requires full coverage, check `complete`
when you enable the Thymeleaf warning option.
